# CUT FREE Management System

This project is organized into two independent applications:

- `frontend/` — React and Vite user interface
- `backend/` — Express API and MongoDB integration

Run the frontend from `frontend/` with `npm install` and `npm run dev`.
Run the backend from `backend/` with `npm install` and `npm run dev`.
The Vite development server proxies `/api` requests to `http://localhost:5001`.
